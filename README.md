# Simple Chating

Pet project for training work with simple chatting.

This project lets users send messages to each other in real time.

## Technologies

- Laravel
- Vue
- PostgreSQL
- DynamoDB
- Pusher

## Run DynamoDB Local

```bash
docker compose up -d dynamodb-local
```

## Run DynamoDB Admin

```bash
docker compose up -d dynamodb-admin
```

Open `http://localhost:8001` in browser.
